# data/mishnah-translit

Transliteration of every Mishnah (63 tractates incl. Pirkei Avot, 4,192 mishnayot) for the
Library Mishnah reader. Generated by `node scripts/build-mishnah-translit.mjs` from
`data/chok-leyisrael/<parasha>.<lang>.json` (do not hand-edit).

## Files
`<tractate-slug>.<lang>.json`, lang in `en|fr|ru|ka` (Hebrew stays in `data/mishnah-index.json`).
`tractate-slug` = the index's `masechet` key with every run of non `[A-Za-z0-9]` replaced by `-`
(trimmed): `Berakhot`, `Maaser-Sheni`, `Bava-Batra`, `Ta-anit` (from `Ta'anit`), `Avot`.
Lookup: `slug = masechet.replace(/[^A-Za-z0-9]+/g,'-').replace(/^-|-$/g,'')`.

## Shape
```json
{ "<chapter number>": { "<mishnah number>": "<transliterated text>" } }
```
Keys are the same numbers as `chapters[].ch` and `mishnayot[].n` in `mishnah-index.json`, as strings.
Every mishnah of the index has an entry (no ranges, no gaps). Text is plain Latin/Cyrillic/Georgian
text (no HTML, no Hebrew letters). Hebrew body can contain `<br>`; translit does not.
Reader: `const tr = (await cachedFetch(dataURL('data/mishnah-translit/'+slug+'.'+lang+'.json')).then(r=>r.json()))[ch]?.[n] || m.text;`
