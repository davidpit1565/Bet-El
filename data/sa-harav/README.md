# data/sa-harav

Shulchan Aruch HaRav (Orach Chayim), vocalized Kehot text from Sefaria.

- `index.json` - `parts[0]`: `simanim` [{n, t (Hebrew nikud title), s (seif count)}] for the 511 non-empty simanim, `missing` = siman numbers empty on Sefaria.
- `oc/<n>.json` - Hebrew `{n,t,s:[...]}`; `oc/<n>.<lang>.json` - phonetic transliteration (en/fr/ru/ka) in the same shape, generated by `scripts/build-sa-harav-translit.mjs`.
- `titles.<lang>.json` (en, fr, ru, ka) - transliterated siman titles for the list, picker and search, so list rendering needs ONE small fetch per language (22-50 KB) instead of 511 siman files.

## titles.<lang>.json shape

A flat object: siman number (string key) -> transliterated title (string). Exactly the 511 keys that are in `index.json` `parts[0].simanim` (never the `missing` ones).

    { "1": "Din hashkamat habboqer", "2": "Din levishat begadim", ... }

Each value is the `t` field of `oc/<n>.<lang>.json`, i.e. the very same deterministic engine/options as the bodies, NFC-normalized, sentence case (first letter capitalized; Georgian has no case). Titles may contain `"` and `[...]` (bracketed words from the Hebrew title). Regenerate with the snippet in the fixlog / re-run after any re-generation of the bodies (`t` is the source of truth).
