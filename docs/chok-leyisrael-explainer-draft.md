# Chok LeYisrael explainer page — current draft (in progress)

Not yet built into the app. This is the latest text the user approved
after several rounds of feedback (see task #16 / CLAUDE.md "Standing open
items"). Confirm with the user before building the actual page — they may
have further edits, and the placement in the app is not yet decided.

Style rules the user gave, explicitly:
- Plain language for end users. No jargon like "cycle", "anchor". No
  comparison to or justification against the traditional printed Chok
  LeYisrael.
- Mature/adult tone — not a children's-book style bare list, but also not
  a wall of technical detail. One line per section is enough, but each
  line should name a concrete daily unit, not just a vague description.
- Musar line lists all 6 book names, without the word "classic".
- (An earlier draft included a line about Leil Shishi — the user asked to
  drop it. Do not re-add it.)
