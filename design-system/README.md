# Tamid · Tehillim — Design Files

עותק מלא של העיצוב של אפליקציית תהילים תָּמִיד, כדי שתוכל להעביר אותו
לאפליקציה אחרת ולקבל את אותו מראה, בלי תלות בטכנולוגיה מסוימת.

## מה יש בתיקייה הזו

- **`beit-el-design-system.css`** — **כל** ה-CSS של האפליקציה, כמו שהוא,
  העתק מלא (לא גרסה מקוצרת/נבחרת). אפשר פשוט לכלול אותו בעמוד ולהשתמש
  באותם class names.
- **`demo.html`** — עמוד תצוגה חי עם חלק מהרכיבים (כרטיסים, כפתורים,
  שורות הגדרות, ניווט תחתון וכו'), כדי לראות בדיוק איך זה נראה ולהעתיק
  ממנו HTML לדוגמה. אפשר לפתוח אותו ישירות בדפדפן.
- **`logo.webp`** — לוגו קהילת בית אל, כקובץ תמונה רגיל (לא מוטמע
  כ-base64 כמו באפליקציה המקורית).

## איך להשתמש (בכל טכנולוגיה — HTML רגיל, React, Vue וכו')

1. לטעון את 4 גופני Google Fonts (השורה המדויקת נמצאת בהערה בראש קובץ
   ה-CSS):
   ```html
   <link rel="preconnect" href="https://fonts.googleapis.com"/>
   <link href="https://fonts.googleapis.com/css2?family=Noto+Serif+Hebrew:wght@400;500;700;900&family=Heebo:wght@400;500;700;800&family=David+Libre:wght@400;500;700&family=Frank+Ruhl+Libre:wght@300;400;500;700&display=swap" rel="stylesheet"/>
   ```
2. לכלול את `beit-el-design-system.css` בעמוד.
3. לשים על תג ה-`<html>`: `dir="rtl" lang="he"` (עובד גם ב-LTR בלי שינוי,
   אם צריך).
4. להשתמש בשמות ה-class כמו שהם על ה-HTML/JSX שלכם — למשל
   `<div class="card">`, `<button class="btn btn-gold">`, שורת הגדרות
   `<div class="set-item">...</div>` — ותקבלו אוטומטית את אותו מראה.
5. מצב כהה/בהיר: לשים `data-theme="dark"` או `data-theme="light"` על
   ה-`<html>`. בלי הגדרה — ברירת המחדל היא כהה.

## הערה על הלוגו

זה קובץ תמונה נפרד (`logo.webp`), אותו לוגו של קהילת בית אל. אפשר
להשתמש בו ישירות, או להחליף אותו בלוגו אחר — שום דבר בעיצוב לא "שבור"
אם משנים את קובץ התמונה.

## שאלות נפוצות

**"יש שם קלאסים שאני לא צריך (לוח שנה, פסוקי תהילים וכו')"** — זה בסדר,
זה קובץ ה-CSS המלא של האפליקציה כמו שהוא. קלאסים שאין להם התאמה
ב-HTML שלכם פשוט לא עושים כלום — אין צורך למחוק אותם.

**"רוצים לשנות צבע"** — כל הצבעים מוגדרים כ-CSS Variables בראש הקובץ
(`--gold`, `--bg`, `--panel` וכו'). שינוי במקום אחד משנה את כל
האפליקציה בבת אחת.
