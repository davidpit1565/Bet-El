# Beit El · Design System

עיצוב משותף לאפליקציות של קהילת בית אל (תהילים, חוק לישראל, בן איש חי...),
כדי שכולן יראו וירגישו כמו בני משפחה אחת — בלי צורך להתחיל עיצוב מאפס.

## מה יש בתיקייה הזו

- **`beit-el-design-system.css`** — קובץ ה-CSS עצמו. משתני צבע/פונט/רדיוס
  (light + dark), וכל הרכיבים החוזרים: כרטיסים, כפתורים, שורות הגדרות,
  מתגים, ניווט תחתון, חיפוש, צ'יפים, תגיות, מודאלים, טוסט, ועוד.
- **`demo.html`** — עמוד תצוגה חי עם כל הרכיבים, כדי לראות בדיוק איך זה
  נראה (וכדי להעתיק ממנו את ה-HTML של כל רכיב). אפשר לפתוח אותו ישירות
  בדפדפן, אין תלות בשום דבר חוץ מהקובץ הזה וב-CSS שלצידו.
- **`logo.webp`** — לוגו קהילת בית אל, בפורמט קובץ רגיל (לא מוטמע ב-base64).
  זה אותו קהילה, אז אפשר להשתמש בו ישירות; אם רוצים לוגו שונה לכל
  אפליקציה, אפשר להחליף את הקובץ הזה בלוגו אחר — שום דבר בעיצוב לא
  "שבור" על זה.

## איך להשתמש (בכל טכנולוגיה — HTML רגיל, React, Vue וכו')

1. לטעון את 4 גופני Google Fonts (יש את השורה המדויקת בראש קובץ ה-CSS,
   בתוך ההערה).
2. לכלול את `beit-el-design-system.css` בעמוד (אחרי כל reset/CSS בסיסי
   משלכם, כדי שהוא יהיה חזק יותר).
3. לשים על תג ה-`<html>`: `dir="rtl" lang="he"` (וזה עובד גם ב-LTR בלי
   שינוי, אם צריך).
4. להשתמש בשמות ה-class כמו שהם על ה-HTML/JSX שלכם — למשל
   `<div class="card">`, `<button class="btn btn-gold">`, שורת הגדרות
   `<div class="set-item">...</div>` — ותקבלו אוטומטית את אותו מראה.
5. מצב כהה/בהיר: לשים `data-theme="dark"` או `data-theme="light"` על
   ה-`<html>`. בלי הגדרה — ברירת המחדל היא כהה.

## מה **לא** נכלל בכוונה

- שום תוכן ספציפי לתהילים/תפילות/תורה (למשל עיצוב הפסוקים, לוח השנה
  העברי) — זה שייך לאפליקציה של תהילים בלבד.
- השם "בית אל" בטקסט — רק הלוגו (התמונה) משותף, לא המיתוג הטקסטואלי,
  כך שכל אפליקציה שומרת על השם שלה.

## שאלות נפוצות

**"אנחנו לא בטוחים איזו טכנולוגיה נשתמש"** — הקובץ הוא CSS רגיל בלי שום
תלות (לא Tailwind, לא ספריית קומפוננטות) — הוא יעבוד בכל אתר/אפליקציית
ווב, כל עוד אפשר לכלול קובץ CSS ולהשתמש ב-class names רגילים.

**"רוצים לשנות צבע"** — כל הצבעים מוגדרים כ-CSS Variables בראש הקובץ
(`--gold`, `--bg`, `--panel` וכו'). שינוי במקום אחד משנה את כל
האפליקציה בבת אחת.
